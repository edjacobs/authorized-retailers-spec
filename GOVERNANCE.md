# Governance

- **Maintainer:** the specification is currently maintained by its founder, Ed Jacobs.
- **Changes in public:** every change is made through a public pull request in this repository, so each change and its reasoning is visible. Proposed changes to the specification are published for at least 30 days of public comment before release.
- **Feedback:** anyone can send feedback at [authorizedretailers.ai/spec](https://authorizedretailers.ai/spec#feedback). The changelog notes where feedback shaped a change.
- **Versioning:** the specification and this package follow semantic versioning. Breaking changes go in a new major version.
- **Future:** as adoption grows, the specification may move to a neutral body.
