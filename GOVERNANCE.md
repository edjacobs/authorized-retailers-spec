# Governance

authorized-retailers.json is an open format with a single registry. The format is open (the specification under CC BY 4.0, the code under Apache 2.0). authorizedretailers.ai is the only registry.

- **Maintainer:** the specification is maintained by Authorized Retailers LLC, which operates the registry at authorizedretailers.ai.
- **Changes in public:** every change is committed to this repository, so each change and its reasoning is visible in the history. This repository doesn't accept pull requests and has no issues. Every change is listed in the changelog.
- **Contributions:** anyone can propose a change, report a case the standard gets wrong or leaves out, or argue against a decision. Email [spec@authorizedretailers.ai](mailto:spec@authorizedretailers.ai) or use the [feedback form](https://authorizedretailers.ai/spec#feedback). No account needed. The maintainer discusses proposals with the people who send them, makes accepted changes in this repository, and the changelog notes where a proposal shaped a change.
- **Versioning:** the specification and this package share one three-part version. Before 1.0, breaking changes can come in a minor version (0.2 to 0.3). The major version changes at most once every 30 days. Changes are batched into releases, and every change is listed in the changelog with the reason for it.
- **Future:** as adoption grows, the specification may move to a neutral body.
