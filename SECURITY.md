# Security

## Reporting a vulnerability

If you find a security problem in the specification, the schemas or this package, such as a way to forge or replay a signed answer, email [SECURITY EMAIL PLACEHOLDER]. Please don't report it through the public feedback form.

Include what you found, how to reproduce it and what an attacker could do with it. We'll acknowledge your report within 3 business days and keep you updated until it's resolved.

Problems with the authorizedretailers.ai registry service itself go to the same address.

## Supported versions

Only the latest release of each major version receives fixes.
